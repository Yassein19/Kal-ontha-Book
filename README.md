منصة متكاملة للمؤلفة **بدور لطفي** للتعريف بكتابها **«كأنثى»** وتقديم استشارات الوعي الذاتي وجودة الحياة، مصحوبة بنظام قراءة رقمي محمي ومقاوم للقرصنة والتسريب بنسبة تتجاوز 95%.

## 🛡️ منظومة حماية القارئ (Anti-Piracy Defense)

طبقًا للمواصفات المعمارية في `plan.txt`، تم تطبيق حماية متعددة الطبقات:
1. **الرسم على الكانفاس (HTML5 Canvas)**: لا يتم أبدًا إرسال ملف PDF الأصلي للمتصفح، ولا تُستخدم وسوم صور `<img>` أو روابط تحميل Blob. يتم رسم كل صفحة كصورة ثنائية الأبعاد مباشرة داخل سياق الكانفاس.
2. **تصريح الصفحة اللحظي (Signed Page Tickets)**: تُطلب كل صفحة بمفردها عبر تصريح رقمي موقع بصلاحية قصيرة (60-90 ثانية) مرتبط برقم القارئ ومعرف جهازه.
3. **الواترمارك الديناميكي المدمج (Canvas Watermark Burning)**: يتم دمج بريد القارئة وبصمة جهازها وتوقيت القراءة مباشرة في بكسلات الكانفاس، مما يمنع إزالتها عبر فحص عناصر المتصفح.
4. **تعطيل منافذ التسريب (Escape Hatches)**:
   - `@media print { body { display: none } }` لحجب الطباعة وتحويل الورقة المطبوعة لصفحة فارغة مع تنبيه قانوني.
   - تعطيل القائمة المنبثقة بالزر الأيمن (`contextmenu`) لمنع "حفظ الصورة".
   - تعطيل تحديد النصوص (`user-select: none`).
   - اعتراض الاختصارات (`Ctrl+P`, `Ctrl+S`, `Ctrl+U`, `F12`).
5. **محدد معدل التصفح (Rate Limiting)**: الخادم يراقب ويقيد الطلبات المتتالية السريعة لمنع محاولات السحب الآلي السريع لصفحات الكتاب.
6. **قفل الجهاز المعتمد (Device-Lock)**: يقترن حساب القارئة تلقائيًا بأول متصفح/جهاز تسجل منه الدخول لمنع تداول الحسابات.

## 🗄️ هيكل المشروع (Folder Architecture)

```
kal-ontha/
├── frontend/                     # تطبيق React مع Vite و Vanilla CSS
│   ├── src/
│   │   ├── components/
│   │   │   ├── Navbar.jsx        # ترويسة الموقع وحالة القارئ
│   │   │   ├── Footer.jsx        # التذييل وبيانات التواصل
│   │   │   ├── ContactForm.jsx   # نموذج التواصل التفاعلي
│   │   │   └── reader/
│   │   │       ├── CanvasPage.jsx    # محرك رسم الصفحات على الكانفاس
│   │   │       ├── Watermark.js      # دمج الواترمارك في الكانفاس
│   │   │       └── ReaderControls.jsx# أشرطة التقليب والسمات والتكبير
│   │   ├── pages/
│   │   │   ├── Book.jsx          # الرئيسية / الكتاب
│   │   │   ├── Author.jsx        # عن الكاتبة
│   │   │   ├── Contact.jsx       # تواصل
│   │   │   ├── Login.jsx         # دخول القارئ
│   │   │   └── Reader.jsx        # القارئ المحمي
│   │   ├── services/api.js       # عميل الاتصال وبصمة الجهاز
│   │   └── index.css             # نظام التصميم والألوان ودرع الطباعة
│   └── package.json
│
├── backend/                      # خادم Node.js Express & SQLite
│   ├── src/
│   │   ├── db/
│   │   │   ├── database.js       # الاتصال بقاعدة البيانات (Node Native SQLite)
│   │   │   ├── schema.sql        # جداول المستخدمين والصفحات والرسائل
│   │   │   └── seed.js           # البيانات الافتراضية وحسابات القارئات
│   │   ├── controllers/          # منطق المصادقة، القارئ، والتواصل
│   │   ├── middleware/           # التحقق من الجلسة ومطابقة الجهاز والـ Rate Limiting
│   │   └── server.js             # نقطة انطلاق الخادم
│   └── storage/pages/            # مخزن الصفحات المشفرة والخاصة
│
├── ingest/                       # أدوات الإدخال ومعالجة الكتب
│   ├── generate-sample-pages.js  # توليد الصفحات النموذجية لكتاب كأنثى
│   └── pdf-to-images.js          # أداة تحويل ملفات PDF إلى صور صفحات فردية
│
└── infra/                        # ملفات النشر العالمية
    ├── nginx/site.conf           # إعدادات Nginx العكسية والترويسات الأمنية
    ├── cloudflare-pages.md       # دليل النشر على Cloudflare Pages و R2
    └── deploy.sh                 # سكربت النشر الآلي
```

## 🚀 التشغيل المحلي السريع (Quick Start)

### 1. تجهيز قاعدة البيانات والصفحات
```bash
npm run generate:pages
npm run seed
```

### 2. تشغيل الخادم الخلفي (Backend)
```bash
npm run dev:backend
# الخادم يعمل على: http://localhost:5000
```

### 3. تشغيل واجهة الويب (Frontend)
```bash
npm run dev:frontend
# الموقع يعمل على: http://localhost:5173
```
